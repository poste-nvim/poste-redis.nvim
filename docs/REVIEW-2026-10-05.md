## Changes

  moved off `exec_run.run_sync` in the async-fetch round, and the
  2026-09-18 review's busy-guard note (a sync call can re-enter a
  running session) describes exactly why nothing should grow back onto
  it. `exec_run.run_sync` itself stays — it is spec-covered and still
  the documented single-shot seam.

## Probed, held (recorded on purpose)

- **The confirm gate cannot be slipped past by case or quoting** —
  probed through the real `extract_entries` path: `flushall`,
  `FlushAll`, `"flushall"` (a quoted head) and `config get …` all
  classify dangerous (`head_of` uppercases before the blacklist;
  `is_dangerous_command` uppercases again defensively), while
  `GET flushall` correctly does not (the key is not the command). The
  gate covers both `<CR>`/visual and `:PosteRedisRunFile`; the browser
  refreshes call `exec_run` directly but only issue their own
  non-blacklisted reads, and the AI path asks its own question.
- **`format.command_failed` is status-driven, exactly as documented**:
  `status = "error"` with a nil / numeric / table / `vim.NIL` error
  text all classify failed without raising; `status = vim.NIL` and a
  missing status do not. `format_result` on hostile values
  (`value = 42`, an unknown type, an empty table) degrades to text
  instead of erroring.
- **The parser tokenizer on hostile lines held**: an unterminated quote
  keeps the raw token (de-quote happens per-consumer and tolerates it),
  control bytes ride inside quoted tokens, `\v`/`\f` separators split
  (the round-27 `%s`-class fix), a bare `#` line and blank/whitespace
  lines produce no entries, `USE` with extra tokens keeps them in
  `tokens` (the use path reads position 2 only).
- **`context.display` / `util.escape_winbar` lack a non-string
  guard** — a numeric connection name reaching the winbar would raise
  on `table.concat`/`:gsub` inside a CursorMoved autocmd. Every
  producer today hands over strings (TOML section names, parser
  tokens); the same class was fixed at the *load* seams where hostile
  data actually arrives (files, job output). Held until one exists.
- The history sidebar's byte-span math re-derived (mark bytes, cmd
  bytes, the last-8-bytes time span, newest-first span↔entry mapping)
  — consistent with `truncate_display`'s display-width cut; no
  findings.
