## Bugs fixed

1. **`yank.current` filled only the `"` register** (`buffer/yank.lua`) —
   `cell` and `column` yank into both `"` and `+`, but the whole-tab
   yank never reached the system clipboard unless the user had mapped
   `unnamedplus` themselves. `current` now targets both, and the
   register targets are pinned by a new spec.

2. **`yank.cell` multiplied with `tab.page_size` / `tab.cursor.row`
   unguarded** — `sort.toggle` defaults the same arithmetic (`or 1`,
   `or 1`) for nil fields; `cell` now matches, so a partially built tab
   cannot crash the yank.

## Feature shipped this pass

- **Result-grid export (P2 "export")** (`buffer/export.lua` +
  `buffer.lua` + config keymap `E`) — on a table tab, `E` picks a format
  (CSV per RFC 4180 quoting / TSV with embedded tabs and newlines
  flattened / JSON, one object per line) and a path (default
  `./poste-redis-<type>-<timestamp>.<ext>`) and writes the WHOLE grid:
  all pages, server order, index column excluded (the same rule `y`
  follows). When the grid holds fewer rows than the collection's total
  (`max-items` truncation) the success notice says so — a partial export
  must be loud. README, the dev file-index (roadmap: export → done),
  the doc site's keymaps page and the dev todo page updated in the same
  pass.

## Recorded, not changed (with rationale)

- **`icons.lua` carries a `hyperlonglong` entry** — not a real Redis
  `TYPE` reply (the type is `hyperloglog`, which is also present). Dead
  defensive config; removing it changes nothing observable.
- **`completion/ctx.fuzzy_match` matches byte-wise on lowercased
  text** — a multibyte pattern char can in principle match across a
  character boundary of the text. Subsequence fuzz is cosmetic here;
  exact filter paths (`search`, glob-escaped scans) are byte-correct.
- **`exec_run.run_async`'s SELECT rebind checks
  `select_targets[payload_idx]` truthiness** — re-verified that Lua's
  0-is-truthy makes an explicit `SELECT 0` rebind correctly to db 0; the
  falsy pitfall does not apply. Left as-is, noted so the next reader
  does not re-suspect it.
