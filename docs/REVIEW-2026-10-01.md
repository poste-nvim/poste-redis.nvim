## Change (with tests)

- **`connections` type-gates `host`/`url` before string ops.** The TOML
  parser turns `host = [1]` into a real table; the resolvers then crashed on
  `:sub` / method calls instead of naming the bad field — and completion,
  the pickers and the statusline all resolve on every redraw, so one typo
  took them all down. A non-string host/url now takes the same clean error
  path as a missing one; the listing keeps the connection (name only).
- **`connections` pickers surface unresolved connections.** A connection
  whose URL cannot be built used to render as a bare name in the
  connection/context pickers, and selecting it silently applied a nil-URL
  context (`context.connection` set, `current_url` nil) that every later
  run fell off of with a generic "No connection resolved". The listing now
  carries `url_err`, the item renders `name  (unresolved: …)`, and
  selecting it names the reason in an error notice instead of applying.
- **`toml` fails closed on malformed inline containers** (re-synced verbatim
  from poste-db, the vendor source): `[1,,2]`, `{ a = 1,, b = 2 }`, `{ = 1 }`
  and `{ a = }` used to drop the malformed entry silently — a vanished
  tunnel target or password changes what the surviving entries mean, with no
  error anywhere. One trailing comma stays legal; `key =` errors instead of
  storing nothing. The vendored-copy pin comment names the new source state.
- **`history.build` tolerates a non-numeric `ts`** (`tonumber` + fallback to
  `os.time()`): `os.date` raises on a string, and push's contract is
  "entry.ts or os.time()", so one future string-typed ts must not be able to
  kill the whole sidebar render.

## Probed, held

- `parser.extract_entries` on 28 hostile files (bare backslash lines,
  unclosed quotes, NUL/high bytes, a 100 KB key, comment-terminated
  continuations, BOM, `USE` variants): every entry survives
  `entry_args` / `entry_text` / `is_dangerous` / `key_arg`, no embedded
  newlines, no wrong-target re-joins.
- `format.format_result` on 28 malformed events (non-array collection
  values, hash entries of arity 1, zset items missing member or score,
  NaN/±inf/2^70 integers, a table-typed `value.type`, string `latency_ms`):
  always a well-formed tab, never an embedded newline, no crash.
- `substitute_vars` self-reference and `A↔B` cycles: depth cap holds, no
  infinite loop; `%` in resolved values is safe (replacement comes from a
  function, so `%1` is never a template).
- `toml.parse` on 50 hostile documents: unterminated quotes/headers, deep
  nesting (200 levels), BOM, `0x`/`1_000`/`.5` forms — errors or lenient
  strings, never garbage in a password field.
- `history.build` with 200-char commands, `%s %d %%`, emoji, and a narrow
  (5-cell) sidebar: spans stay inside the line, no negative pads.
- `docs.lookup` with nil/number/table, and all ~200 DOCS entries through
  `doc.build_lines`: no embedded newlines (buffer lines would reject them).

## Observations (not changed — recorded on purpose)

- **JSON export stringifies number cells.** `buffer/export.to_json` maps
  cells through `grid.to_copy` (= `util.to_clipboard`), so a zset score
  exports as `"score": "1"` rather than `"score": 1`. Yank-consistency is
  the point (`y` copies the same text), and the transform-level contract
  ("to_copy passthrough keeps types") is pinned in export_spec — a real
  typed-JSON export would want its own `to_json` copy function.
- **`session_conn.execute` sends `SELECT 0` on the first db-steered request**
  even when the connection is already on db 0 (server default) — one extra
  round-trip per fresh session, kept because `session.db` starts unknown and
  guessing would risk a silent wrong-db command.
- The inline-container comment strip eats `#` before container parsing, so
  `t = { a = # c }` reports "Unclosed inline table" rather than a
  missing-value error — still fail-closed, just with a coarser message.
